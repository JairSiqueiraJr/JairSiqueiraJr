### Olá!! Eu sou o Jair Siqueira!
Sou desenvolvedor em formação com foco em backend e engenharia de dados, construindo soluções reais orientadas a problemas do mundo corporativo.

Atualmente desenvolvo o ClickTech, um sistema completo de Help Desk projetado para simular ambientes reais de suporte técnico. O projeto envolve modelagem de banco de dados, controle de fluxo de chamados, rastreamento de mudanças de status com histórico via triggers e estruturação de dados para futuras análises e métricas operacionais.

Tenho experiência prática com suporte técnico, o que me proporciona uma visão clara dos desafios enfrentados por usuários e empresas, permitindo desenvolver sistemas mais eficientes, funcionais e alinhados com necessidades reais.

Possuo conhecimentos em Python, JavaScript e SQL, com foco crescente em backend, bancos de dados e arquitetura de sistemas.

🎯 Busco oportunidades como Desenvolvedor Backend ou Engenheiro de Dados, onde eu possa contribuir com soluções escaláveis, orientadas a dados e com impacto real.

🚀 Construindo projetos reais, evoluindo constantemente e pensando como engenheiro.
